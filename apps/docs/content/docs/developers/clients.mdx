The repository includes generated contracts and language clients. Node, Python, Go, and Swift use the shared Rust client through native bindings. Install from a source checkout or local distribution artifacts containing matching native libraries until a corresponding registry release is available. Package namespaces do not claim publication. Source builds use the tools pinned in the root `mise.toml`; start development commands from the checkout root.

| Client | Requirement | Source directory |
| --- | --- | --- |
| TypeScript | Node 22+ for native HTTP and owned stdio | `sdk/typescript` |
| Python | Python 3.11+ | `sdk/python` |
| Go | Go 1.22+, cgo, and a C compiler | `sdk/go` |
| Swift | Swift 6; macOS and Xcode for native builds | `sdk/swift` |

## TypeScript

Build from the checkout root using the shared Bun workspace. This stages the native Node-API module and builds the TypeScript package, which depends on `@swarmie/contracts`.

```sh
cd /absolute/checkout
bun install --frozen-lockfile
just sdk-build
bun run --cwd sdk/typescript build
```

Browser applications can import `@swarmie/client/browser`, which uses Fetch without a native library.

```ts
import { Client } from '@swarmie/client';

const client = Client.http('http://127.0.0.1:7457');
await client.initialize();
const session = await client.spawn({ harness: 'codex', cwd: '/absolute/project' });
const key = crypto.randomUUID();
// Persist key before submitting an intentional prompt.
await client.prompt(session.id, 'Describe the project.', key);
for await (const event of client.events(session.id, { afterSequence: session.sequence })) {
  if (event.type === 'text.delta') process.stdout.write(event.data.text);
  if (event.type === 'turn.ended') break;
}
await client.close(session.id);
client.dispose();
```

Present any `permission.requested` event and respond through `permission/respond`. Use `try/finally` to close an owned session when integrating this example into an application. An uncertain submission must be recovered before sending another intentional prompt.

## Python

Stage the Rust shared library from the checkout root before installing the source package. The Python build backend rejects source packages without that library. Prebuilt platform wheels already include it.

```sh
cd /absolute/checkout
just sdk-build
python3 -m pip install ./sdk/python
```

```python
import uuid
from swarmie_client import Client

client = Client.http('http://127.0.0.1:7457')
client.initialize()
session = client.spawn({'harness': 'codex', 'cwd': '/absolute/project'})
key = str(uuid.uuid4())
# Persist key before sending; retain it for recovery.
client.prompt(session['id'], 'Describe the project.', key)
for event in client.events(session['id'], after_sequence=session['sequence']):
    if event['type'] == 'turn.ended':
        break
client.close(session['id'])
client.dispose()
```

## Go and Swift

Run `just sdk-build` from the checkout root to stage Go's static Rust library, then use the local Go module `swarmie.local/client` with a `replace` directive pointing to `sdk/go`.

On a macOS build host, run `just sdk-build-apple` from the checkout root to create the macOS/iOS XCFramework. Swift applications can then add a local SwiftPM dependency on `sdk/swift` and import `SwarmieClient`. Matching distribution archives include these native artifacts.

The Go client uses contexts for cancellation. Swift uses structured concurrency and task cancellation. All language clients expose generic RPC calls alongside typed helpers. HTTP is their common transport; [the transport matrix](/docs/runtime/transports/) lists the maintained alternatives.

## Contracts and generation

`packages/contracts/protocol.json` is the canonical exported wire schema. `packages/contracts/index.d.ts` contains runtime types; `ui-client.d.ts` contains scoped client contribution authoring types. [Download the schema](/contracts/protocol.json) or browse [method groups](/docs/reference/protocol-methods/).

Generate client files from a built runtime's schema export:

```sh
cargo run -p protocol --example export_schema > /absolute/artifact/protocol.json
python3 sdk/tools/generate.py --schema /absolute/artifact/protocol.json
```

Runtime invocation and UI contributions have distinct ownership. See [extensions](/docs/extensions/) for the client-side API.
