These captures show the actual implemented desktop UI with **fixture projects, messages, connection data, and simulated dictation**. The demo captures no audio. Periwinkle borders and labels are measured documentation overlays, linked to the corresponding [slot contracts](/docs/extensions/slots/).

The desktop interface has a minimum width of 760 pixels. Screens, panels, settings sections, messages, context menus, and composer states use separate captures to expose normally empty contributions.
