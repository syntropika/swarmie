# Swarmie

Swarmie is a modular application platform that brings together extensible capabilities,
persistent work and shared interfaces.

Choose the capabilities your application needs and combine them into a coherent whole.
Each part has a clear responsibility, giving your application room to grow.

## What Swarmie offers

- **Composable capabilities.** Add and combine plugins to shape your application.
- **Work that can continue.** Preserve progress and resume unfinished tasks after a restart.
- **Flexible storage.** Keep application data and task progress with independently chosen providers.
- **Shared interfaces.** Build web and native experiences around a common visual language.
