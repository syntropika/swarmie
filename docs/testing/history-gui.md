# Native history and prompt recovery acceptance

This fixture runs the installed Pi CLI and the actual NativeSDK GTK/WebKit host on a private Xvfb display and minimal private D-Bus. A local deterministic Chat Completions server supplies responses and one real Pi `write` tool call. No user credentials, upstream inference, or browser substitute are used.

The initial history is generated by two actual external Pi CLI commands. The acceptance actions use OS input to discover/import that history, inspect its native tree, branch before a selected user message, attach PNG/PDF/text through the native file picker, quote an earlier response, send another message, and edit the older complex message in a new branch. The verifier compares the original and resend model requests and canonical user content, checks exact image/PDF bytes and the conversation prefix, and verifies that the original CLI journal is unchanged.

The explicit file restore flow uses an owned managed Git worktree. Actual Pi modifies `one.txt`; fixture setup commits that result and closes other owned sessions. The GUI closes the selected session and restores the before-turn checkpoint through its confirmation dialog. Verification checks exact earlier bytes, unchanged branch head, and untouched main checkout. Pi has no native conversation rollback, so this does not certify Codex or Claude rollback.

Run with fresh external artifacts and an external directory containing valid `fixture.png` and `fixture.pdf`:

```sh
python3 tests/fixtures/history-gui/acceptance.py \
  --artifacts /absolute/external/history-run \
  --media /absolute/external/media
```

The process emits readiness metadata and accepts JSON lines on stdin. It supports the shared desktop actions plus `dialog-key`, `dialog-type`, `dialog-click`, `wheel`, `capture-display`, `verify-source`, `prepare-restore`, and `verify-restore`. File chooser actions discover its window only on the owned private display. Text uses slower OS typing to allow the controlled inputs to settle. `--script` runs an initial JSON array, then keeps stdin available. In scripts and interactive input, `{{artifacts}}` expands to this run's artifact directory.

End stdin to close all owned native sessions, processes, and the local model server. Verify completed receipts with:

```sh
python3 tests/fixtures/history-gui/verify.py /absolute/external/history-run --require-restore
```

Screenshots, model request receipts, journals, build hashes, input actions, and cleanup receipts stay outside the repository. Coordinate-based actions assume the fixture's 1280×900 native window; inspect each state before reusing coordinates with a changed interface.
